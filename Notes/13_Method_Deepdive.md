# Lesson 13 - Methods

## What is a Method?

A method is a reusable block of code that performs a specific task. Methods help organize programs into smaller, manageable pieces.

---

## Why Use Methods?

- Improves readability
- Avoids duplicate code
- Makes debugging easier
- Makes programs reusable
- Follows the Single Responsibility Principle

---

## Method Syntax

```csharp
returnType MethodName(parameters)
{
    // code
}
```

```Example
int Add(int a, int b)
{
    return a + b;
}
```
