# Lesson 14 - Inheritance

## Objective

Learn how to make use of inheritance. Child class inherit from parent class.

---

## Algorithm
  Start

    ↓

Create Person class

    ↓

Define common properties
(Name, Age, Email)

    ↓

Create virtual DisplayInfo() method

    ↓

Create Student class inheriting from Person

    ↓

Override DisplayInfo()

    ↓

Call base.DisplayInfo()

    ↓

Display student's Score

    ↓

Create Teacher class inheriting from Person

    ↓

Override DisplayInfo()

    ↓

Call base.DisplayInfo()

    ↓

Display teacher's Salary

    ↓

Instantiate Student and Teacher objects

    ↓

Call DisplayInfo() on each object

    ↓

Program Ends
